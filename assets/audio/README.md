# 🔊 Audio — 자작 프로시저럴 사운드 (CC0)

이 게임의 효과음/BGM은 외부 파일을 다운로드하지 않고,
`js/audio.js`의 Web Audio API 신스 코드로 실시간 생성됩니다.

- SFX: click / hit / crit / heal / aoe / win / lose
- BGM: 16스텝 밝은 8비트풍 루프 (C–F–G–C)
- 음소거 버튼(#btn-mute) → localStorage에 저장

라이선스: 본 프로젝트 저작자가 직접 작성한 코드이므로 **CC0 (퍼블릭 도메인)** 으로 자유 사용 가능.
외부 핫링크 없음, repo 내 코드에 포함됨.
